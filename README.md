# Raman R – Portfolio

Static portfolio site (HTML, CSS, JS). No build step. Photo and resume are already included.

## Deploy on GitHub Pages
1. Create a public repo named `RamanRakkaiah.github.io` under github.com/RamanRakkaiah.
2. Upload everything in this folder to the repo root (keep `assets/`).
3. Repo → Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
4. Live at https://RamanRakkaiah.github.io in about a minute.

Any other repo name also works; the URL becomes `https://RamanRakkaiah.github.io/<repo-name>/`.
